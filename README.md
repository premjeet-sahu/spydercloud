# spydercloud

This repository is a public proof-of-concept workspace.

## Repository Navigation

This repo uses branches to separate different proof-of-concept projects.

The `main` branch is the navigation branch. It explains how the repository is organized and points visitors to the available PoC branches.

To view a specific PoC:

1. Open the branch selector on GitHub.
2. Select the PoC branch you want to inspect.
3. Read the README and source code inside that branch.

## Available PoC Branches
